# ॥ जय श्री कृष्ण ॥ Janmashtami 2026 Web Deployment Guide

This folder contains the complete, static web application ready to deploy to [Vercel](https://vercel.com).

## What's Included:
* `index.html`: Responsive, mobile-first devotional web experience.
* `style.css`: Glassmorphism UI with golden devotional glow.
* `app.js`: Interactive canvas particles + Web Audio procedural Bansuri flute synthesizer (works instantly in any browser without needing external audio files).
* `krishna_animated.mp4`: Seamlessly looping 9:16 devotional wallpaper video.
* `preview.jpg`: Instant mobile poster image.
* `vercel.json`: Edge caching and streaming configuration.

---

## 🚀 How to Deploy on Vercel (Takes 1 Minute)

### Method 1: Using the Vercel CLI
From this `web/` directory in your terminal:
```bash
cd web
npx vercel
```
Follow the prompts (choose default settings). Your live URL will be generated immediately!

---

### Method 2: Via GitHub & Vercel Dashboard
1. Push your repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import your repo.
3. In **Root Directory**, click **Edit** and select `web`.
4. Click **Deploy**.

Done! Your Janmashtami 2026 live wallpaper will be live worldwide on Vercel's global CDN.
